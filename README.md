# Dammer kleurenconfigurator

Statische Dammer configurator met canvas-lagen voor romp, kussens en teakdeck.

## Publiceren

Upload de volledige inhoud van deze map naar een statische host, of gebruik GitHub Pages met `index.html` in de root.

## Bestanden

- `index.html` bevat de configurator en kleurkeuzes.
- `images/` bevat het Dammer-logo en de gerenderde bootlagen.
